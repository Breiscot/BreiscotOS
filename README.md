Welcome to BreiscotOS!

In this README I can give you instructions on:

• Terminal commands you can use.

• How to use the Browser with available URL.

• Games folder.

• Dock features.

• Writer Saving System.

• Calculator keys.



1. Terminal Commands you can use:
    You can use in the terminal the commands below:

      clear               |   To clear the terminal
   
      neofetch            |   To view system information
   
      curl parrot.live    |   To start the parrot ASCII animation

3. How to use the Browser with available URL:
    When you open your browser, you'll see the default site https://www.wikipedia.org.
    You can use it to search Wikipedia, but if you want to use other sites, make sure they don't have Clickjacking protection,
    HTML sites can't open web links with this protection.
    So, here are the sites I've found that don't have this protection:

      https://www.wikipedia.org | What you'll see by default in the browser
   
      https://archive.org       | This is Internet Archive, you can open it

5. Games folder:
    I added a folder inside the main folder, namely the Games,
    inside you can find some games, in this folder you can find:

      MineAndSurvive       |   A mining and survival game, yes the title says all (is created by me)
   
      Minecraft            |   Is Minecraft (not the original obviously)
   
      Slither.io           |   Is Slither.io for web but I added this in Games folder

7. Dock features:
    The Dock has some features you can see, such as icons popping up when you hover your cursor over icons in the Dock.
    If you make a window full-screen, you can see the Dock disappear, but if you hover your cursor down, you can see it reappear.

8. Writer Saving System:
    In the Writer application, you can save your text within the BreiscotOS itself,
    just click the Save button with the floppy disk icon inside the app,
    it will not say anything about the fact that it is saved,
    once clicked when you reload the site page you will always be able to review it from that save point.

9. Calculator keys:
    In the Calculator application, Instead of typing directly by pressing on the grid,
    you can quickly type the numbers you want to calculate directly on the keyboard.
    You can do this with the respective keys:

      To do Basics operations         |   Type '+', '-', '*', '/', '.', '%'
   
      To Calculate the numbers        |   Type 'Enter' or '='
   
      To Clear the Calculator         |   Type 'Escape' or 'Delete'
   
    To Delete last Character        |   Type 'Backspace'
